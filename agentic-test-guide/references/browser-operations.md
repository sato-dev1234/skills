# 画面操作と検証結果の記録

手順作成時の実画面確認と、本検証の両方に適用する。ツールの操作方法は[playwright-cliの使い方](playwright.md)を読む。

## 操作する範囲を守る

操作は、依頼と手順が示す範囲で、利用者が画面上で行える定型操作と、画面や操作結果を確認する操作に限る。

- 任意スクリプト、Cookieや保存データの書き換え、通信の差し替えによって、状態を読み取ったり変えたりしない。
- 許可された同一オリジン内で操作する。
- 手順にない状態変更や範囲外の操作が必要になったら、その操作と再開条件を示して停止する。
- 依存関係のインストールやプロジェクト設定の変更を行わない。

操作対象は画面で確認できる名前や役割で指定し、表示中の要素を一つに決める。画面全体の何番目かという指定で選ばない。一つに決まらなければ停止し、手順作成へ戻って確認する。

## 操作して確認する

実行単位ごとに操作と観測を進め、実行した操作、観測結果、証跡、停止理由をその都度記録する。証跡は一つのディレクトリに、順序と内容が分かる名前で保存する。

| 状況 | 行うこと |
|---|---|
| 認証が必要 | 認証情報の入力を利用者に委ねる。接続を維持し、完了通知後に同じ接続の対象オリジンへ戻った画面で再開条件を確認する |
| 利用者の操作・判断を待つ | 接続とアプリを維持し、引き渡す内容と再開条件を伝える |
| 予期しないダイアログが出た | 推測で応答せず、文言と停止理由、必要な応答を報告する |
| 操作がタイムアウトした | 同じ更新操作を再送せず、再観察で実行済みか不明かを記録する |
| 期待した結果にならない | 同じ操作を繰り返さず、観測結果を記録して該当ケースを止める |
| 手順の不足や画面の変化が分かった | 該当ケースの手順作成へ戻る。推測で操作を置き換えて続行しない |

停止したケースに依存するケースは進めない。独立した準備済みのケースは進められる。途中で停止しても、結果整理と可能な後始末の確認は行う。

## 観測結果から判定する

| 確認できた状態 | 判定 |
|---|---|
| 期待との一致と必須証跡が揃う | 合格 |
| 期待との相違を観測した | 不合格 |
| 相違を確定できず、観測または必須証跡が不足する | 判定不能 |
| まだ実行していない | 未実施 |
| 相違を観測したが必須証跡を保存できない | 不合格と証跡不足を併記 |

期待結果を定めない観察は観測記録とし、合格件数へ含めない。事前確認の記録は、本検証の合格として流用しない。

結果には、ケースと手順、実施者、実装・環境、実行時点、入力、期待結果、観測結果、判定、証跡、停止理由を対応付ける。未実施のケースには、未実施理由と再開に必要なことを残す。

## 途中から再開する

接続と前提を再確認し、状態変更済みの操作を無条件に繰り返さない。操作が実行済みか判断できなければ、その不明点を解消するまで再送しない。

実装・環境・条件・手順が変わった場合は、影響するケースの手順と前提を再確認する。以前の実行結果を保持したまま、新しい実行時点と結果を残す。
