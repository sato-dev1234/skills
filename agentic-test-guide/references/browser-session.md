# ブラウザの接続・維持・終了

## 対象画面へ接続する

指定された既存接続がある場合は、対象タブと操作を許可されたオリジンを確認して使う。オリジンはURLのスキーム・ホスト・ポートの組である。候補のタブが複数あり、依頼と現在の状態から一つに決められない場合は、対象の確認を再開条件として停止する。

ブラウザを起動する場合は、次に従う。

- アプリが利用可能になってから、確定した対象URLで開く。`about:blank`や推測したURLで開かない。
- ブラウザは`chromium`、`chrome`、`msedge`から選び、省略時は起動コマンドに同梱された`chromium`を使う。`chrome`と`msedge`は明示指定された場合だけ使い、利用できなくても別のブラウザへ切り替えない。
- 一連の作業では同じ接続を使う。権限の異なる利用者の同時検証など、別の接続が必要な場合は用途を分ける。新しい接続には対象が分かる識別子を付け、既に使われている名前を避ける。
- 開いたタブが対象URLと同じオリジンであることを確認してから、画面の観察へ進む。
- ブラウザや操作ツールが不足している場合はインストールせず、停止理由と再開条件を残す。

ツール固有のコマンドは[playwright-cliの使い方](playwright.md)を読む。

## 再開と終了のために情報を残す

操作に使う接続の識別子、対象タブとオリジン、使用するアカウントの区別を控える。認証情報そのものは記録しない。

終了のためには、自分がブラウザを起動したのか、既存ブラウザに接続したのか、既存の接続を借りたのかを区別し、その根拠と終了・解放方法を控える。接続の識別子が分かるだけで、ブラウザを終了してよいとは判断しない。

## 維持・終了する

| 場面・対象 | 行うこと |
|---|---|
| 利用者待ち・手動確認 | アプリと接続を維持し、残っている対象と再開・終了に必要な情報を返す |
| 通常終了時の、自分が起動したブラウザ | 自分の起動を確認できる対象だけを終了する |
| 通常終了時の、既存ブラウザへ自分が作った接続 | 接続だけを解放し、ブラウザは残す |
| 呼び出し元から借りた接続 | 勝手に解放・終了せず、維持して引き渡す |
| 所有を確認できない対象 | 終了せず、残っている状態と必要な確認を報告する |

すべてのブラウザをまとめて終了する操作や、プロファイルの削除は使わない。アプリの終了は[Webアプリの終了](web-app-session.md)に従い、後始末の状態を検証判定と別に記録する。
