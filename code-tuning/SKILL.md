# コードチューニング

変更したコードを共通化、品質、効率、不具合検出の観点で評価し、修正可能な指摘を実コードへ反映する。

## 位置づけ

本スキルは、コードチューニングで確認する対象、評価観点、指摘の扱い、修正範囲、完了判定、出力規則を定める。

評価者の起動、評価結果の整理、重複指摘の統合、修正、再評価、起動できない場合の扱い、最終報告の作り方は、共通の反復改善ルールに従う。

## 参照ファイル

| 参照資料 | 役割 |
|---|---|
| 対象と修正範囲の参照資料 (`references/scope.md`) | 対象、評価、指摘の扱い、修正範囲 |
| 完了判定の参照資料 (`references/completion-gate.md`) | 完了判定、検証、出力規則 |
| 共通化の参照資料 (`references/commonization.md`) | 共通化の評価観点 |
| 品質の参照資料 (`references/quality.md`) | 品質の評価観点 |
| 効率の参照資料 (`references/efficiency.md`) | 効率の評価観点 |
| 不具合検出の参照資料 (`references/defect.md`) | 不具合検出の評価観点 |

## 読み方

実行担当者は、共通の反復改善ルールを読んだうえで、まず対象と修正範囲を確認する。評価観点を決めた後、該当する参照資料を読む。停止判断と最終報告前には完了判定の参照資料を読む。
