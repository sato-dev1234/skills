# ガイドの用途

依頼の目的から候補を選び、該当するガイドを読む。工程の詳細や作業規則は各ガイドで確認する。

| 作業 | ガイド | 読んで判断すること |
|---|---|---|
| チケットと作業場所の準備・管理 | `ticket-guide` | 対象、管理ルート、チケット・worktreeの扱い、概要の更新 |
| 要件・設計・実装・レビュー・完成確認 | `development-guide` | 対象工程、根拠となる資料、作成・更新する文書、完了条件 |
| 原因・挙動・変更内容・影響範囲の調査 | `investigate-code` | 調査対象、比較元、確認できる根拠、調査の範囲 |
| 実画面による手順確認・検証 | `agentic-test-guide` | 検証内容、実画面確認、実行、記録、残件 |
| 文章の作成・書き直し・レビュー、コミットメッセージ | `writing-guide` | 原文と根拠、ツリーへの整理、言葉、文章化、照合 |
| 文書の作成・更新 | `document-guide` | 読み手と用途、構成、テンプレート、形式、保存と表示確認 |

文書を伴う工程では、工程のガイドに文章作成と文書作成のガイドを組み合わせる。文章だけを返す依頼やコミットメッセージには、文書テンプレートを強制しない。資料更新だけの依頼から、開発全体や不要な検証を始める指示に広げない。
