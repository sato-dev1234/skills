# テストチューニング

変更したテストコードを検証充足、独立性、安定性、網羅性の観点で評価し、信頼性上の問題を修正する。

## 位置づけ

本スキルは、テストチューニングで確認する対象、評価観点、指摘の扱い、修正範囲、完了判定、出力規則を定める。

評価者の起動、評価結果の整理、重複指摘の統合、修正、再評価、起動できない場合の扱い、最終報告の作り方は、共通の反復改善ルールに従う。

## 参照ファイル

| 参照資料 | 役割 |
|---|---|
| 対象と修正範囲の参照資料 (`references/scope.md`) | 対象、評価、指摘の扱い、修正範囲 |
| 完了判定の参照資料 (`references/completion-gate.md`) | 完了判定、検証、出力規則 |
| 検証充足の参照資料 (`references/assertion.md`) | 検証充足の評価観点 |
| 独立性の参照資料 (`references/isolation.md`) | 独立性の評価観点 |
| 安定性の参照資料 (`references/stability.md`) | 安定性の評価観点 |
| 網羅性の参照資料 (`references/coverage.md`) | 網羅性の評価観点 |

## 読み方

実行担当者は、共通の反復改善ルールを読んだうえで、まず対象と修正範囲を確認する。評価観点を決めた後、該当する参照資料を読む。停止判断と最終報告前には完了判定の参照資料を読む。
