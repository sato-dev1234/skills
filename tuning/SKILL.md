# 反復改善の共通ルール

本スキルは、独立した評価者を使って対象を評価し、指摘を整理し、必要な修正と再評価を行うための共通ルールと作業の進め方を持つ。

## 評価条件を決める

反復改善では、利用者の指示、または使用側 skill の規則から、評価条件を決める。評価条件は、対象、評価観点、判定項目、評価者へ渡す依頼、修正範囲、停止条件、出力形式を指す。

| 判断 | 扱い |
|---|---|
| 使用側の評価手順や規則が示されている | その内容に従う |
| プロンプト、文章、設計案、または改善対象が示されている | その対象から評価条件を組み立てる |
| 指示から条件を一意に決められる | 評価前に今回の条件として固定する |
| 複数解釈により収束判定または成果物の意味が変わる | 評価前に確認する。確認できない場合は未確認事項に分ける |
| 指示範囲外の条件がある | 今回の対象外として記録する |

条件を固定した後は、独立評価者を起動し、結果を整理し、判定項目の達成を反復ごとに判定し、起動不能などの停止理由を分けて扱う。使用側 skill が示されている場合は、使用側の規則を共通の反復改善ルールへ適用する。

独立評価者とは、現在の担当者とは別に新規起動し、対象を白紙で読む評価者を指す。起動できない場合は評価を実施せず、起動不能の理由と未実施の事実だけを報告する。

本スキルまたは本スキルの共通ルールに従う使用側 skill を実行する場合、独立評価者の起動はその評価手順の実行要件として扱う。起動可否は、明示的な起動禁止と起動手段の有無で判断する。追加評価者、委任、または並列作業が明示的に禁止されている場合は起動しない。起動手段がない場合、または起動が成立しない場合は、独立評価を実施したように書かず、起動不能として扱う。

## 使用側 skill との関係

使用側 skill は、評価対象、評価観点、判定項目、評価者へ渡す依頼の具体文、修正範囲、完了判定、出力規則を定める。

本スキルの参照ファイルは、独立評価者の起動、評価結果の整理、指摘の統合、再評価、起動不能、継続中と最終報告の分離を扱う。
